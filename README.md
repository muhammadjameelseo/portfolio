# Jamil Buzdar | SEO Portfolio Website

Static 7-page portfolio website. No build step, no database.

All files sit in one folder, so any upload method works. Keep every file in the same place.

| Page | File |
|---|---|
| Home | `index.html` |
| About | `about.html` |
| Services | `services.html` |
| Skills and tools | `skills.html` |
| Experience | `experience.html` |
| Case studies | `case-studies.html` |
| Contact (form) | `contact.html` |

Shared files: `style.css` (design), `main.js` (menu, image viewer, form), `favicon.svg`, and the `.webp` screenshots.

## Publish with GitHub Pages

1. Upload every file to the repository (select all files and drag them in).
2. Open **Settings > Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
3. The site goes live at `https://YOUR-USERNAME.github.io/REPO-NAME/`.

## Contact form: one-time activation

Messages go to `jamilbuzdar634@gmail.com` through FormSubmit.

1. Open `contact.html` on the live site and send one test message.
2. Click the activation link FormSubmit emails you (check Spam too).
3. After that, every message arrives in your inbox.

## Editing

- Change wording in any `.html` file.
- Colors and fonts: the `:root` block at the top of `style.css`.
- Earlier jobs: in `experience.html`, copy the `<article class="role">` block and edit it.
